[klkhk]plugin_qiandao_1.12.2 · 更新日志 ​

v1.1.4 ​

当前版本 · 适用 Minecraft 1.12.2

新增 ​

  • 七日周期奖励，第 7 天终极大奖，第 8 天循环且连续天数继续累计
  • 连续签到 7 / 14 / 30 天额外奖励，支持全服广播
  • 补签卡系统：右键打开补签面板、二次确认、消耗 1 张补签卡、连续天数恢复
  • 在线奖励：累计在线满设定时长自动发卡，每日上限
  • 签到排行榜：右侧实时计分板 + /qd rank 图形化面板
  • 三种经济联动：ZPoints / PlayerPoints / Vault
  • 签到标题、音效、粒子特效、今日槽位附魔发光

优化 ​

  • 玩家数据异步定时保存，停服同步保存
  • 自动清理 60 天前日期记录，防止 data.yml 膨胀
  • 排行榜使用每位玩家独立计分板，不干扰主计分板
  • 1.12.2 计分板 16 字符限制用 Team 前缀/后缀方案绕开

命令 ​

  • /qd、/qd rank、/qd help、/qd givecard、/qd reload

版本规则 ​

v主版本.次版本.修订号

位变化含义兼容性
主版本架构或核心逻辑重构配置可能不兼容
次版本新增功能配置向下兼容
修订号问题修复、细节优化完全兼容

升级注意 ​

  1. 备份 config.yml 与 data.yml
  2. 删除旧 config.yml，替换 jar
  3. 重启生成新配置
  4. 迁回自定义内容
  5. /qd reload 验证
